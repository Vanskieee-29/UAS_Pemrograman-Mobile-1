## 🧩 Overview
Aplikasi ini merupakan sistem pencatatan keuangan sederhana berbasis Android yang memungkinkan pengguna melakukan monitoring pemasukan dan pengeluaran secara cepat dan efisien. Aplikasi dirancang dengan tampilan UI yang bersih, minimalis, dan mudah digunakan sehingga cocok untuk pengguna pemula maupun pengguna yang ingin mencatat transaksi harian tanpa kerumitan.

## 🎯 Purpose / Goals
Membantu pengguna mengelola keuangan harian dengan lebih teratur.
Menyediakan fitur pencatatan transaksi yang ringkas dan mudah diakses.
Menampilkan total saldo berdasarkan pemasukan dan pengeluaran yang sudah dicatat.
Memberikan pengalaman pengguna yang simple dan intuitif.

## 👤 Target Users
Mahasiswa
Karyawan pemula
Siapa saja yang ingin mencatat pengeluaran secara cepat tanpa aplikasi yang terlalu kompleks

## ✨ Key Features
1. Pencatatan Pemasukan
Input jumlah uang masuk
Input tanggal transaksi
Input kategori
Data langsung dihitung ke total saldo

2. Pencatatan Pengeluaran
Tambah pengeluaran dengan jumlah, tanggal, dan kategori
Saldo otomatis berkurang sesuai nilai transaksi

3. Dashboard Utama
Menampilkan ringkasan saldo
Rekap pemasukan dan pengeluaran
Navigasi cepat ke tambah transaksi

4. Riwayat Transaksi
List transaksi secara kronologis
Pemisahan pemasukan & pengeluaran

## 🛠 Tech Stack
Android Studio
Kotlin sebagai bahasa utama
XML untuk UI
SQLite / Room Database untuk penyimpanan lokal
Menggunakan komponen Material Design untuk tampilan modern dan konsisten

## 🎨 UI/UX Notes
Menggunakan warna ungu (default MaterialTheme) sebagai warna utama tombol dan komponen interaktif
Layout dibuat responsif dan mudah dibaca
Navigasi dibuat sesederhana mungkin agar pengguna dapat menambahkan transaksi dalam hitungan detik
Mockup, storyboard, dan UI sudah dirancang di Figma untuk menjaga konsistensi visual
